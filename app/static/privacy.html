Privacy notice

RingBreaker is an open source hackathon research prototype submitted to the PayPal AI Hackathon 2026. This system is designed solely to evaluate graph neural network architectures on synthetic financial transaction patterns.

Data handling and sandbox scope

All account identifiers, device fingerprints, and payment transactions processed in this prototype are synthetic demo entities. No real personal identifiable information, cardholder numbers, or banking credentials are collected, stored, or processed.

PayPal sandbox credentials

Any sandbox client keys used during integration are stored exclusively in your local environment file and never transmitted to external third party servers, telemetries, or hosted logging tools.

Local storage and audit logging

Analyst review decisions and transaction events are stored in a local SQLite file on your instance for audit trail inspection. You can reset all state at any time via the admin controls.
